# Bulle TOEIC

Application de flashcards et de quiz pour réviser le vocabulaire du TOEIC.

556 mots en 16 listes thématiques, 3 niveaux (470–725, 730–855, 860–990), révision espacée, quiz QCM et suivi de progression.

Pour l'installer sur iPhone : ouvrir la page dans Safari, toucher Partager puis « Sur l'écran d'accueil ».
